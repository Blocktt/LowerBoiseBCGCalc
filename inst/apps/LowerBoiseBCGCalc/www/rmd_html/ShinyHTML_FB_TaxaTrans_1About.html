Prepare an input file with File Builder

Step 1: Create the input file

The input file must be a comma-separated file (CSV). It can include data for multiple samples, sites and Index Classes.

REQUIRED fields. Column heading names in the input file are flexible (use drop-down menus to match).

Column Name  Fish Bugs Data Type Allowable entries Description
SampleID x x text flexible Unique sample identifier
TaxaID x x text flexible Taxon name
Count x x numeric non-negative real numbers; should not be blank Number of individuals
Index_Class x x text see list below (must match exactly) Tells R which rules and metrics to apply, based on class
Length x numeric non-negative real numbers; blanks are OK Length, units = mm

OPTIONAL fields can be included as well and will be carried through into the output file. If you include DELT anomalies (fish) and density (bugs) the column names must match what is shown below.

Column Name  Fish Bugs Column Heading Name Data Type Allowable entries Description
N_Anomalies x must match exactly numeric non-negative real numbers; blanks are OK number of individuals with Deformity, Erosion, Lesion or Tumor (DELT) anomalies
Density_m2 x must match exactly numeric non-negative real numbers; blanks are OK number of individuals per meter squared (count x subsample correction factor x area correction factor)

Index Classes:

  • Main_BarberPool

  • Main_Eckert

  • Main_VetGlen

  • Main_SoChannel

  • Main_Middleton

  • Main_NotusParma

Sites can be matched with the appropriate class/stream segment using these geospatial (shapefile and kmz) files [ZIP].

Step 2: Go to the ‘Import File’ tab and upload the input file

Step 3: Go to the ‘Prepare Input File’ tab and run File Builder

The File Builder joins the taxon name in the input file with the ‘Taxon_orig’ column in the Taxa Translator table and performs two functions:

  • Translates the original taxon name to the proper Operational Taxonomic Unit (OTU) for the BCG calculation.

  • Adds in new columns with taxa attributes and hierarchy (e.g., Order, Family) that are needed for the metric calculations.

The Lower Boise River fish and macroinvertebrate Taxa Translator and Taxa Attribute tables are available online.

When the File Builder has finished running, a prompt box will appear. It will notify you if your File Builder run was successful or failed. Or, in some cases (e.g., if there are problems with your input file), the screen will gray out (meaning the Shiny app has crashed) and you’ll have to refresh the app, investigate potential problems with your input file, and try again.

If your run was successful, the prompt box will alert you if there are taxa in your input file that don’t match with the taxa list in the Taxa Translator table.

What if there are non-matching taxa? Open the ‘BCG_TaxaTranslator_nonmatches’ file and view the list of non-matching taxa. If the non-matches are due to a misspelling, extra space or other small issue, fix the non-matching taxa in your input file, re-upload the file via the ‘Import File’ tab, and rerun the File Builder (and to prevent confusion, delete the first set of output files with the non-matching taxa). If the non-matching taxa are legitimate taxa that need to be added to the Taxa Translator table, notify Jen Stamp (Jen.Stamp@tetratech.com) and Tetra Tech will update the Taxa Translator table as soon as resources permit.

Step 4: Download and unzip the results

A ‘results’ folder will appear, with the following subfolders:

Folder Description
_user_input original input files
reference taxa translator, taxa attribute and fish age class files
results_Bugs_BCG bug outputs from the File Builder (and eventually the BCG calculator as well)
results_Fish_BCG fish outputs from the File Builder (and eventually the BCG calculator as well)

In the results subfolders, there will be four File Builder output files, described below.

Output file Description
BCG_TaxaTranslator_modifications shows list of taxa in the input file; to see which taxa names were modified during the Taxa Translation process for reasons other than capitalization scheme, filter the Modified_woCAPS column = TRUE
BCG_TaxaTranslator_nonmatches taxa in your input file that don’t match with the taxa list in the Taxa Translator table
BCG_TaxaTranslator_Results_wAttributes input file is now ready to go! The taxa names have been translated to the BCG OTU and attributes and hierarchy added in. Import this file into the Shiny app and run the BCG calculator
BCG_TaxaTranslator_sources shows which calculation was selected, which Operational Taxonomic Unit (OTU) column was used, and which versions of the Taxa Translator and Attribute tables were used
